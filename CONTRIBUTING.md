# Contributing

All issues and pull requests are ignored.

Questions and focused feedback can be sent to
[info@neutral.dev](mailto:info@neutral.dev).

Please do not send code or attachments.

Every email must include the following statement:

> I confirm that I have authority to submit this contribution and to make
> the dedication and grant the license stated here. I dedicate it under
> CC0 1.0 Universal and also license it under the Zero-Clause BSD license
> (0BSD), allowing recipients to choose either.

Emails containing code or attachments, or missing the statement above,
will be ignored.
